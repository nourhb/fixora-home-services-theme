# Fixora — Home Services WordPress Theme

A bold Full Site Editing (block) theme for home-service businesses: plumbers, HVAC technicians and electricians.

## Design

- Deep navy (`#0b2a4a`) + energetic ember orange (`#f97316`)
- 24/7 emergency CTA hero with pulsing badge
- Phone number prominent in the header top bar
- Inter typeface (bundled, OFL licensed)
- "Midnight" dark style variation included

## Templates

| Template | Purpose |
|---|---|
| `front-page.html` | Hero, trust badges, services, how-it-works, stats, testimonials, service area, booking CTA |
| `page-services.html` | Detailed services grid + pricing plans + FAQ |
| `page-about.html` | Story, values, team photo + stats + testimonials |
| `page-contact.html` | Quote request form + contact info + service area |
| `page.html` / `page-wide.html` | Standard and wide page layouts |
| `single.html`, `archive.html`, `search.html`, `index.html`, `404.html` | Blog and utility templates |

## Block patterns (13)

`hero-emergency`, `trust-badges`, `services-grid`, `how-it-works`, `stats-band`, `testimonials`, `pricing-plans`, `faq`, `cta-booking`, `contact-info`, `service-area`, `about-story`, `quote-form`
