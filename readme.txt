== Description ==

Fixora is a bold Full Site Editing theme built for home-service businesses — plumbers, HVAC technicians and electricians. Deep navy and energetic orange design, 24/7 emergency CTA hero, trust badges, services grid with pricing hints, how-it-works steps, animated stats, testimonials, FAQ, service-area coverage and a quote-booking CTA — everything a trades business needs to win jobs online.

A clean, modern Full Site Editing (block) theme built with theme.json. Includes multiple page templates, curated block patterns, and a "Midnight" style variation. Translation-ready and accessibility-conscious.
